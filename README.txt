PREMIUM TELEGRAM FILE UPLOAD BOT

1. Install Python 3.10+.
2. Install dependencies:
   pip install -r requirements.txt

3. Set environment variables:
   BOT_TOKEN=your_bot_token
   ADMIN_ID=your_numeric_telegram_id

   Or edit the fallback values in bot.py.

4. Run:
   python bot.py

Features:
- /start premium-style menu
- Upload Photo
- Upload Video
- Upload Document/File
- Sends uploaded files to ADMIN_ID
- Upload confirmation
